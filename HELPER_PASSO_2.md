# 🎬 HELPER: PASSO 2 - CAPTURAR SCREENSHOTS (MODO AUTOMÁTICO)

Esse arquivo ajuda você a capturar screenshots SEM se perder!

---

## ⚡ COMECE AQUI - 3 PASSOS RÁPIDOS

### 1️⃣ ABRA EMULADOR/DEVICE

**Se tem emulador Android:**
```bash
# No terminal
npm start

# Escolha: a (Android)
# QR code aparece
```

**Se tem device Android físico:**
```bash
# USB conectado
npm start
# Escolha: a (Android)
# Scan QR com device
```

**Se não tem nenhum:** Use Appetize.io (online)
```
https://appetize.io/
Upload seu APK/AAB
Execute na nuvem
```

---

## 🎯 NAVEGAÇÃO RÁPIDA

Siga EXATAMENTE esta sequência:

### Screenshot #1: HOME
```
1. App abre → Você vê Home screen
2. TIRE SCREENSHOT AQUI
3. Salve como: screenshots/01-home.png
✅ Pronto!
```

### Screenshot #2: DIABETES OVERVIEW
```
1. Clique em: "Diabetes" (na navegação inferior)
2. TIRE SCREENSHOT AQUI
3. Salve como: screenshots/02-diabetes-overview.png
✅ Pronto!
```

### Screenshot #3: GLICEMIA
