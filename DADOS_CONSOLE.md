```
Leviã é um aplicativo de rastreamento de saúde desenvolvido para ajudar no acompanhamento de diabetes.

RECURSOS:
• Rastreie níveis de glicemia
• Registre medicações e horários
• Acompanhe refeições e carboidratos
• Faça notas sobre sua saúde
• Interface simples e intuitiva
• Dados salvos localmente no seu dispositivo

⚠️ AVISO IMPORTANTE:
Leviã NÃO é um dispositivo médico. Este aplicativo foi desenvolvido como ferramenta de acompanhamento pessoal e educacional. Ele NÃO substitui consulta médica profissional.

SE VOCÊ TIVER UMA EMERGÊNCIA:
- BRASIL: Ligue 192 (SAMU) ou 911
- Dirija-se ao pronto-socorro mais próximo
- Fale com seu médico para cuidados profissionais

Este aplicativo é apenas para acompanhamento pessoal. Sempre consulte seu médico ou endocrinologista para diagnóstico, tratamento e recomendações médicas.

SOBRE OS DADOS:
Todos os seus dados são armazenados localmente no seu dispositivo. Nenhuma informação é enviada para servidores externos.
```
